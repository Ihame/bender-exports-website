# Bender Exports Website

Official website for Bender Coffee Company Ltd - Genuine coffee from the heart of Africa.

## About

Bender Coffee Company Ltd was established in 2017 by Mr. Horanimpundu Jean Paul and Ms Uwamariya Odette, driven by their passion for coffee and their commitment to contributing to Rwanda's development.

## Features

- Responsive design built with Bootstrap
- Interactive hero slider showcasing washing stations
- Information about three coffee washing stations:
  - **Musaza** (Kirehe District)
  - **Nyungwe** (Rusizi District)
  - **Nyarubaka** (Kamonyi District)

## Deployment

This site is configured for deployment on Vercel. Simply connect your GitHub repository to Vercel and it will automatically deploy.

### Vercel Deployment

1. Go to [Vercel](https://vercel.com)
2. Import your GitHub repository
3. Vercel will automatically detect the static site configuration
4. Deploy!

The site will be available at `https://bender-exports-website.vercel.app` (or your custom domain).

## Local Development

To run locally:

```bash
# Using Python
python -m http.server 8080

# Or using Node.js
npx serve .
```

Then open `http://localhost:8080` in your browser.
